# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズ株式会社のコーポレートサイトです。
「毎晩、確実に灯るソフトウェアを。」をキャッチコピーに、夕暮れのビル群をモチーフにしたデザインで構成しています。

## サイトの概要

1ページ構成の静的サイトで、以下のセクションがあります。

| セクション | 内容 |
| --- | --- |
| お知らせ | 最新のニュース |
| フロアガイド | サービス一覧（UI／UXデザイン、アプリケーション開発、API・データ連携、クラウド基盤、運用・保守）をエレベーターのフロア案内風に紹介 |
| 実績 | 配車計画システムの刷新、予約・事前問診アプリ、工場の稼働データ基盤などの導入事例 |
| 開発の進め方 | ヒアリング → プロトタイプ → スプリント開発 → リリースと運用 |
| 会社概要 | 会社名、設立、代表者、社員数、所在地、事業内容 |
| 採用情報 | 募集職種など |
| お問い合わせ | 問い合わせ窓口 |

- ライト／ダークテーマに対応しています（OS の設定に追従します）。
- フォントは Google Fonts から読み込みます。そのほかに外部ライブラリやビルド手順はありません。

## ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS を1ファイルにまとめています）
└── README.md
```

## ブラウザで開く手順

ビルドやサーバーは不要です。HTML ファイルをブラウザで直接開くだけで表示できます。

### 方法1：エクスプローラーから開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、ファイルを右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウにファイルをドラッグ＆ドロップしてください。

### 方法2：コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 補足

- Google Fonts を読み込むため、インターネットに接続した状態で開くと、デザインどおりのフォントで表示されます。オフラインの場合は OS 標準のフォントで表示されます。
